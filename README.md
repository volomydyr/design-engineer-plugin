# Design Engineer Plugin

A Claude Code plugin marketplace for the **design-engineer** plugin -- a full-stack product design and AI-assisted development toolkit.

## Installation

```bash
claude plugin marketplace add https://github.com/volomydyr/design-engineer-plugin
claude plugin install design-engineer
```

## What's Inside

- **[design-engineer](./plugins/design-engineer/)** -- Opinionated workflow from research through psychology-informed UX to production code. 9 agents, 7 commands, 48 skills.
