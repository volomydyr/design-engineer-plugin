# Landing page structure reference

## Above-the-fold formula

Communicate value within 5 seconds. The fold must contain:

1. **Headline**: 6–12 words stating the outcome (not the product)
2. **Subheadline**: 15–25 words explaining how
3. **Hero image**: Shows outcome, not product (lifestyle over screenshots)
4. **Primary CTA**: Action verb + value ("Start annotating" not "Submit")
5. **Social proof**: Logos, counts, or testimonials

### Headline formulas (conversion-tested)

- [Outcome] without [pain]
- [Outcome] in [timeframe]
- The [better way] to [common task]
- Stop [pain]. Start [outcome]
- [Number] [things] to [outcome]

---

## 9-section page order

1. **Hero** – headline, subheadline, CTA, social proof
2. **Social proof** – logos, user count, star ratings, trust badges
3. **Problem** – pain point, emotional language, 2–3 specific scenarios
4. **Solution/Features** – how product solves it, 3–5 key features with benefit descriptions
5. **How it works** – 3–4 simple steps, icon + description per step, closing CTA
6. **Testimonials** – quote + name + role + company
7. **Pricing** (if applicable) – feature comparison, recommended plan, money-back guarantee
8. **FAQ** – 5–7 common objections with clear, confident answers
9. **Final CTA** – urgency or scarcity element, risk reversal (guarantee), value-reinforcing button text

---

## CTA button rules

### Text
- Start with action verb
- Specific outcome ("Start annotating" not "Get started")
- First-person language ("Start my free trial" not "Start your free trial")
- Urgency ("Get instant access" not "Sign up")
- Never: "Submit", "Click here", "Learn more"

### Design
- High contrast against background
- 44px minimum height
- Above fold + repeated in sections 5, 7, 9
- Generous whitespace around button
- One primary CTA per viewport (don't compete with yourself)

---

## Social proof types (ordered by processing speed)

1. **Company logos** – fastest to process, highest trust
2. **User count** – scale signal ("50,000+ users")
3. **Star ratings** – quality signal
4. **Testimonials** – credibility through specifics
5. **Case study stats** – specificity ("reduced feedback time by 73%")
6. **Trust badges** – security, certifications

---

## Form design

- Every field reduces conversion ~11%
- Maximum: name + email (2 fields)
- Single-column layout
- Inline validation (show errors as user types)
- Never ask for information you don't need

---

## Mobile optimization

1. Full-width CTA buttons
2. Sticky CTA on scroll
3. 16px minimum font size
4. 48x48px minimum tap targets
5. Responsive images (srcset or picture element)
6. Stack horizontal layouts vertically
7. Reduce image sizes for mobile (hero <200KB)

---

## Page speed targets

- Hero image: <200KB
- Total page weight: <2MB
- Largest Contentful Paint (LCP): <2.5s
- Lazy load all below-fold content

---

## Common mistakes

| Mistake | Fix |
|---------|-----|
| Vague headline ("Welcome to the future") | Specific outcome ("Annotate AI drafts 10x faster") |
| Weak CTA ("Submit") | Action + value ("Start annotating free") |
| Product screenshot as hero | Lifestyle image showing outcome |
| Multiple competing CTAs | One primary CTA per section |
| No social proof above fold | Add logos, count, or star rating |
| Too many form fields | Name + email only |
| Desktop-only layout | Mobile-first, full-width CTAs |
| No urgency | Time-limited offer, limited spots, or risk reversal |

## Copy frameworks

### PAS (Problem-Agitate-Solution)
1. Identify the pain point
2. Amplify the consequences of inaction
3. Present your solution

### AIDA (Attention-Interest-Desire-Action)
1. Grab attention with bold claim
2. Build interest with details
3. Create desire with benefits
4. Prompt action with CTA

### StoryBrand (recommended when StoryBrand deliverable exists)
1. Hero (customer) has a problem
2. Meets a guide (you) who understands
3. Guide gives them a plan
4. Calls them to action
5. Action results in success / avoids failure

Use the framework that best matches the existing deliverables. If a StoryBrand canvas exists, use StoryBrand – the narrative is already written.
