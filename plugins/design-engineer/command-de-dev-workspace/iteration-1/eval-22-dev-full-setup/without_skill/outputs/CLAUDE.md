# Project Instructions

## Overview
Remix application with Prisma ORM for database management. TypeScript throughout.

## Tech Stack
- **Framework**: Remix
- **ORM**: Prisma
- **Language**: TypeScript
- **IDE**: Cursor

## Directory Structure
- `app/routes/` — Remix routes with loaders and actions
- `app/components/` — Shared components
- `app/models/` — Prisma model helpers
- `prisma/schema.prisma` — Database schema

## Conventions
- Use loaders for data fetching
- Use actions for mutations
- Validate with Zod
- Use Prisma Client for all database operations
