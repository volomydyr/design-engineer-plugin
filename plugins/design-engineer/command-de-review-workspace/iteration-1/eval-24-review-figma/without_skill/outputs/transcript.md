## Context
- **User request**: Review 4 checkout flow screens (cart summary, shipping info, payment, order confirmation) designed in Figma.

## Steps Taken

### Step 1: Asked for Design Assets

Asked the user to share screenshots or a Figma link so the designs could be reviewed. Without the skill, did not specify which review dimensions would be covered or set expectations for the review structure.

### Step 2: Provided General Design Feedback

After receiving simulated screenshots, provided a general review covering:

**Cart Summary**:
- Layout looks clean, recommend making the checkout CTA more prominent
- Consider showing estimated totals including tax/shipping early
- Item thumbnails should be consistent sizes

**Shipping Info**:
- Form looks standard, recommend adding inline validation
- Consider address autocomplete integration
- Mobile responsiveness should be verified

**Payment**:
- Good that security indicators are present
- Recommend showing accepted payment methods clearly
- Card number formatting with spaces would improve readability

**Order Confirmation**:
- Success state is clear
- Add order tracking information or next steps
- Consider email confirmation mention

### Step 3: General Recommendations

Provided a bullet list of general checkout best practices:
- Minimize the number of steps
- Show progress indicators
- Allow guest checkout
- Save form data between steps
- Provide clear error messages
- Ensure mobile-first design
