**Step 5:** Walks through the handoff process: select frame in Figma, use MCP to read properties, prompt AI with "implement this screen," review output, iterate on discrepancies.

**Step 6:** Sets expectations: 2-3 hours in Figma for key screens vs 2-3 days traditional approach. AI handles state variations, responsive layouts, edge cases.
